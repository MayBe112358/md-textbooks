# md-textbooks

存放转换成 Markdown 的教材和复习资料，方便复习，也方便交给 AI 阅读。

## 目录结构

每本教材单独建一个文件夹，教材正文和相关的测验题、重点题放在同一个文件夹里。

| 文件夹 | 内容 |
| --- | --- |
| [物理学第七版下册](物理学第七版下册/) | 马文蔚《物理学》（第七版）下册：第 9–13 章正文、两次平时测验题 |

## 约定

- 教材正文里的插图只保留了 `[插图：…]` 形式的占位和图注，没有图片本身。
- 标 `\*` 的节、小节和题目是教材中的选学内容。
- 转换时发现的原文错误，会在括号里注明原文怎么写。
